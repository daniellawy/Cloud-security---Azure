# Microsoft Sentinel — Incidents

## Objective

Review, triage, and manage security incidents generated by Microsoft Sentinel.

## 1. Review Incidents

```text
Microsoft Sentinel
→ Threat management
→ Incidents
```

Review:

* Incident name
* Severity
* Status
* Owner
* Creation time
* Related alerts

## 2. Open Incident

Select the incident and review:

```text
Incident
├── Description
├── Severity
├── Status
├── Owner
├── Alerts
└── Entities
```

## 3. Take Ownership

Assign the incident to the investigating analyst.

```text
Incident
→ Assign
→ Select analyst
```

## 4. Update Status

Move the incident through the appropriate investigation state.

```text
New
 ↓
Active
 ↓
Resolved
```

For an incident requiring further investigation:

```text
Status: Active
```

## 5. Review Related Alerts

```text
Incident
→ Incident timeline
→ Alerts
```

Review the alerts contributing to the incident and inspect their associated entities and events.

## Validation

* [ ] Incident reviewed
* [ ] Severity reviewed
* [ ] Incident assigned
* [ ] Status updated
* [ ] Related alerts reviewed
* [ ] Entities reviewed

## Result

A Sentinel incident was triaged, assigned to an analyst, and moved to an active investigation state with its associated alerts and entities reviewed.
