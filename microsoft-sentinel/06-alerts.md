# Microsoft Sentinel — Alerts

## Objective

Review alerts generated by Microsoft Sentinel analytics rules and validate the associated detection data.

## 1. Review Alerts

```text
Microsoft Sentinel
→ Threat management
→ Alerts
```

Review:

* Alert name
* Severity
* Status
* Creation time
* Analytics rule
* Associated entities

## 2. Review Alert Details

Select an alert and inspect:

```text
Alert
├── Description
├── Severity
├── Status
├── Detection rule
├── Entities
└── Related events
```

## 3. Validate Detection

Trace the alert back to the telemetry that triggered it.

```text
Analytics Rule
      ↓
KQL Query
      ↓
Matching Events
      ↓
Alert
```

Verify:

* The alert was generated by the expected analytics rule.
* The underlying events match the detection logic.
* Relevant entities are identified.
* Alert severity is appropriate for the lab scenario.

## Validation

* [ ] Alert generated
* [ ] Alert details reviewed
* [ ] Analytics rule identified
* [ ] Underlying events reviewed
* [ ] Entities reviewed
* [ ] Detection validated

## Result

A generated Sentinel alert was reviewed and its detection logic and underlying telemetry were validated before incident-level investigation.
